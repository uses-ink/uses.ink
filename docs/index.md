# uses.ink documentation

uses.ink turns a folder of markdown, in a git repository or an Obsidian vault, into a blog with no
configuration. These pages are the design of the product and of the `ink` binary, built by `ink`
itself from the `docs/` folder of the repository ([how](site.md)). Pre-release: the
[roadmap](roadmap.md) says what is built.

## Start here

- [Architecture](architecture.md): what each part does, where it runs and the contracts between parts.
- [The `ink` command line](cli.md): every command, option, output and exit code.
- [Roadmap](roadmap.md): the milestones in order, each with an exit check that can fail.

## Design

- [Authentication](auth.md): passkeys, sessions, recovery and the step-up, with no passwords.
- [Hosted on Cloudflare](hosted.md): the implementation plan for the hosted service.
- [Tracing](tracing.md): the process log, `INK_LOG` and the log file.
